# Tea in the Hegemony

Narrative social-espionage RPG — chapter **The Reception**.

Godot **4.3**, **Compatibility** renderer (browser-friendly), typed GDScript.

## Run

```bash
godot --path .
# or
./.bin/godot --path .
```

Main scene: `scenes/main/boot.tscn`

## Verify

```bash
./tools/run_tests.sh
```
